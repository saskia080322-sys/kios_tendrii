# Kios Tendri — Website UMKM

## 📋 Deskripsi Proyek
Website ini dibuat untuk memudahkan pelanggan melihat daftar produk, memesan barang, dan membantu pemilik kios dalam mengelola data produk serta pesanan secara lebih terorganisir.

## 📁 Struktur Folder
- *admin/* — Halaman pengelolaan produk, pesanan, dan pelanggan
- *components/* — Navbar dan footer yang dipakai di semua halaman
- *database/* — File koneksi ke database MySQL
- *public/css/* — File gaya tampilan website
- *public/images/* — Gambar produk dan logo
- *app/* — File fungsi tambahan
- *beranda.php* — Halaman utama
- *produk.php* — Daftar produk
- *keranjang.php* — Keranjang belanja
- *pemesanan.php* — Form pemesanan

## 🛠️ Teknologi yang Digunakan
- Bahasa Pemrograman: PHP
- Basis Data: MySQL
- Antarmuka: HTML, CSS
- Server Lokal: XAMPP
