# Kios Tendri — Website Pemesanan Barang

## 🏪 Informasi Mitra
- Nama: Kios Tendri
- Jenis Usaha: Toko Kebutuhan Harian
- Lokasi: Rampoang, Sulawesi Selatan

## 🛠️ Teknologi
- Bahasa: PHP
- Database: MySQL
- Tampilan: HTML & CSS
- Server: XAMPP

## 📂 Struktur Folder
kios_tendri/
├── assets/        ← Gambar, CSS
├── database/      ← Koneksi & Database
├── beranda/       ← Halaman Utama
├── produk/        ← Daftar Barang
├── pemesanan/     ← Form Pesanan
├── kontak/        ← Info Toko
├── pengaturan/    ← Ubah Info Toko
├── navbar.php
└── footer.php

## 🚀 Cara Menjalankan
1. Buka XAMPP → nyalakan Apache & MySQL
2. Buka phpMyAdmin → buat database: kios_tendri
3. Impor file: database/db_produk.sql
4. Buka browser → ketik: localhost/kios_tendri
